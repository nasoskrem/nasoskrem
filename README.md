* **[KRUMA: High-Performance CPU AI Core](https://github.com/nasoskrem/Kruma_AI-Accelerator)**
  A custom, low-level deep learning engine built entirely from scratch in Rust. Designed to execute N-dimensional tensor operations and automatic differentiation without relying on external BLAS libraries or GPU acceleration.
  * **Hardware Acceleration:** Features cache-aware matrix multiplication with 4x4 register blocking and SIMD vectorization (using the `wide` crate) to process multiple floating-point operations per CPU cycle.
  * **Custom Tensor Engine:** Implemented O(1) memory space broadcasting through spatial stride manipulation and mapped N-dimensional coordinates to contiguous 1D heap allocations.
  * **Deep Learning Modules:** Engineered fully connected layers, regularizations (Inverted Dropout), an Adam Optimizer, and loss functions.
